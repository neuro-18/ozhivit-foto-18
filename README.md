# AI Image-to-Video Review 2026

Static one-page editorial review of image-to-video AI services.
Hosted with GitHub Pages as a project subdirectory.

## Stack

- Plain HTML5 + CSS3
- No frameworks, no build step
- System fonts + Georgia serif, no external dependencies

## Structure

- `index.html` — single page with review
- `style.css` — stylesheet (dark blue-violet theme)
- `robots.txt` — crawler directives
- `sitemap.xml` — sitemap for search engines

## Live

The site is served at a subdirectory of the parent GitHub Pages domain.
